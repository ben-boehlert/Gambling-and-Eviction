THE PROBLEM
════════════════════════════════════════════════════════════════════════════════

Your CS-DiD estimation pipeline was CRASHING with segfaults when running on
unbalanced panel data.

Root Cause Identified:
  • DRDID's reg_did_rc() called fastglm() with 0-row design matrices
  • fastglm's C++ function colMax_dense() segfaults on empty input
  • 537 out of 875 (g,t) cells had n_treat_post=0 (treated units not observed)
  • No bounds checking → instant crash

Impact:
  • Unable to estimate CS-DiD on your gambling-eviction data
  • No publishable estimates
  • No support diagnostics for paper

════════════════════════════════════════════════════════════════════════════════
THE SOLUTION
════════════════════════════════════════════════════════════════════════════════

Created comprehensive patch suite with:

1. PREFLIGHT SUPPORT CHECK (preflight_support_check.R)
   • Diagnoses support issues BEFORE estimation
   • Computes full 875-cell support table
   • Identifies exact reason for each non-identifiable cell
   → Ready for Appendix Table A1

2. PATCHED DRDID FUNCTION (reg_did_rc_safe.R)
   • Guards against empty matrices at lines 94-99 and 110-115
   • Returns structured NA instead of crashing
   • Logs reason for failure (n_treat_post=0, n_control_post=0, etc.)
   → No more segfaults!

3. SAFE CS-DID WRAPPER (att_gt_safe.R)
   • Runs preflight check automatically
   • Transparent reporting of NA cells
   • Enhanced result object with support metadata
   • Safe aggregation with correct reweighting
   → Publication-ready estimates

4. PRE-TRENDS VISUALIZATION (plot_csdid_pretrends.R)
   • Event study plots with pre-trend highlighting
   • Joint hypothesis tests for parallel trends
   • Group-specific dynamics
   • Support heatmaps
   → Complete visualization suite
